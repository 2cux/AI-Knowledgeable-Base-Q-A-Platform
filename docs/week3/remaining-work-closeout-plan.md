# 剩余工作收尾计划

目标：用 7 天完成投简历前最小收尾，把后面一周留给 Java 基础和项目面试准备。原则是不再做大规模新功能，只做可运行、可验收、可讲清楚。

## 第 1 天：项目可运行性修复

- 当天目标：保证项目能在本地从空库启动。
- 具体任务：
  - 新建空 MySQL 数据库，验证 Flyway V1-V18 全量迁移。
  - 检查 `application.yml`、`application-dev.yml`、环境变量配置。
  - 检查 API Key 是否必须通过环境变量注入。
  - 跑现有单元测试，记录失败项。
- 交付物：
  - 空库启动验证结果。
  - 需要修复的问题清单。
- 验收标准：
  - 应用能启动。
  - Flyway 不报错。
  - 不需要手工改表即可运行。
- 时间不够可砍：
  - 暂不新增测试，只记录现有测试状态。

## 第 2 天：README / docs / 接口文档整理

- 当天目标：让别人打开仓库能看懂项目并跑起来。
- 具体任务：
  - 重写或修复 README 乱码。
  - 补充项目介绍、技术栈、启动步骤、环境变量、数据库初始化说明。
  - 补充核心接口调用顺序。
  - 检查 docs、SQL、核心注释乱码。
- 交付物：
  - 新 README。
  - 可读的 docs 核心文档。
- 验收标准：
  - README 无乱码。
  - 说明清楚如何配置 MySQL、JWT、LLM、Embedding。
  - 明确 Debug 接口仅本地使用。
- 时间不够可砍：
  - 不修所有源码注释，只修 README、核心 docs、SQL 关键注释。

## 第 3 天：Apifox 核心链路验收

- 当天目标：用接口证明项目闭环可跑。
- 具体任务：
  - 注册 / 登录。
  - 创建知识库。
  - 上传 txt / md 文档。
  - process。
  - embed。
  - chat/ask。
  - 查看问答详情、会话列表、会话详情。
  - 提交反馈。
  - 管理端查看问答详情、未命中、反馈、热门问题、统计。
  - 验证 force 重处理、force 重新 embedding、删除。
- 交付物：
  - Apifox 验收记录。
  - 示例请求参数和返回截图或文字记录。
- 验收标准：
  - 主链路至少完整跑通一次。
  - 至少覆盖一个未命中拒答样例。
  - 管理端接口能使用管理员 token 访问。
- 时间不够可砍：
  - 管理端 TopN 和 stats 可只保留文字验证，不做截图。

## 第 4 天：简历项目描述与面试讲解稿

- 当天目标：把项目转换成能投递、能讲的材料。
- 具体任务：
  - 整理 4-6 条简历 bullet points。
  - 准备 30 秒项目介绍。
  - 准备 2 分钟项目介绍。
  - 准备 5 分钟技术深挖主线。
  - 标出不能夸大的点：MySQL + Java cosine、MVP、无 Redis / MQ / 微服务。
- 交付物：
  - 简历项目描述。
  - 面试讲解稿。
- 验收标准：
  - 每条简历描述都能在代码中找到依据。
  - 讲解中能说明项目不足和优化方向。
- 时间不够可砍：
  - 暂不做架构图，用文字架构替代。

## 第 5 天：模拟面试问题准备

- 当天目标：准备常见追问，避免面试时卡住。
- 具体任务：
  - 准备 RAG、Embedding、文档切片、向量存储、检索、拒答相关问答。
  - 准备 Spring Security、JWT、权限校验相关问答。
  - 准备 MySQL 表设计、索引、Flyway 相关问答。
  - 准备项目不足和生产优化方案。
- 交付物：
  - 高频问题清单。
  - 每题 30-60 秒回答思路。
- 验收标准：
  - 至少覆盖 20 个高频问题。
  - 能不看稿讲清楚 RAG 主链路。
- 时间不够可砍：
  - 不准备太偏的八股扩展，优先项目相关。

## 第 6-7 天：缓冲与修 bug

- 当天目标：修复验收中发现的阻塞问题，保持项目稳定。
- 具体任务：
  - 修复启动、迁移、接口验收中的阻塞 bug。
  - 清理临时日志、无用文件和敏感配置。
  - 最后跑一次核心链路。
  - 对 README 和简历描述做最终核对。
- 交付物：
  - 可投递版本。
  - 最终验收记录。
- 验收标准：
  - 本地启动成功。
  - 核心链路可跑通。
  - 文档无明显乱码。
  - 简历描述不夸大。
- 时间不够可砍：
  - 不做新功能。
  - 不做复杂 UI。
  - 不接入新中间件。

## 停止开发条件

满足以下条件即可停止功能开发，转入面试准备：

- 空库启动成功。
- 核心 Apifox 链路跑通。
- README 和 docs 核心文档无明显乱码。
- API Key 没有泄露。
- RAG 命中、未命中、LLM 不可用至少有说明或样例。
- 简历 bullet points 已准备。
- 30 秒、2 分钟、5 分钟项目介绍已准备。
