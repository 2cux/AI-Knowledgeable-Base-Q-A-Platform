# Frontend

AI 知识库问答平台前端项目，使用 React + Vite + TypeScript + React Router + Axios + Tailwind CSS。

## 开发

```bash
npm install
npm run dev
```

默认访问地址：

```text
http://localhost:5173
```

## 构建

```bash
npm run build
```

## 环境变量

开发环境后端地址配置在 `.env.development`：

```text
VITE_API_BASE_URL=http://localhost:8080
```

## 目录

```text
src/
├── api/
├── components/
├── pages/
├── router/
├── types/
└── utils/
```
